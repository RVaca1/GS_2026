# 🌌 Monitoramento Energético - Missão Espacial

**Global Solution | Soluções em Energias Renováveis e Sustentáveis**  
**Disciplina:** Ciência da Computação - 1CC

## 📋 Sobre o Projeto

Sistema inteligente de monitoramento para missão espacial experimental com foco em **energias renováveis** (painéis solares) e **sustentabilidade**. 

O sistema simula o monitoramento em tempo real de uma base espacial, analisando consumo energético, geração solar, temperatura, comunicação e nível de bateria.

## ✨ Funcionalidades

- Monitoramento em tempo real de variáveis energéticas
- Geração automática de alertas em condições críticas
- **Tomada de decisão autônoma** (redução de consumo, modo econômico, etc.)
- Inserção manual de dados
- Persistência de logs em arquivo CSV
- Geração de relatório final da missão
- Interface clara via terminal
